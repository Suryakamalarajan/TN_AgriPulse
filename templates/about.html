About the Project

Why TN AgriPulse exists

Project Purpose

TN AgriPulse is an educational agricultural market intelligence project focused on Tamil Nadu crop prices, mandi trends, and simple data analysis for learning. It helps students understand how commodity data is gathered, cleaned, and visualized.

Technology Stack

The application uses Python, Flask, SQLite/MySQL, HTML, CSS, JavaScript, Bootstrap, Pandas, NumPy, requests, and Chart.js to build a complete data analytics website.

Official Data Source

The project is designed to use the official government dataset available on data.gov.in, titled “Current Daily Price of Various Commodities from Various Markets (Mandi)”. The application reads the API key from an environment variable and stores valid records after checking each response.

Python Data Analytics

Python and Pandas are used to clean, summarize, compare, and visualize agricultural records. This helps users understand price differences, crop averages, market comparisons, and historical trends.

Educational Scope and Limitations

This project is for academic learning and demonstration. It does not claim to be an official government portal, and data may be limited by API availability, field completeness, or local database updates. Users should compare records carefully and keep unit, date, and commodity compatibility in mind.
